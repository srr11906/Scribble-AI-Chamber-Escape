# Rule: Kalki 2898AD Thematic Mapping

This document outlines the planned terminology, interface labeling, and system notifications rebranding to transition **Scribble: AI Chamber Escape** to a **Kalki 2898 AD** dystopian sci-fi theme.

---

## 1. Core Terminology Refactoring Map

* **Chamber / Room** $\rightarrow$ **Uplink Outpost** (or **Sector**)
* **Chamber Code** $\rightarrow$ **Uplink Access Key**
* **Oxygen Points (PTS)** $\rightarrow$ **Units** (Kasi currency)
* **Chamber Subjects** $\rightarrow$ **Access Seekers** (or **Kasi Outcasts**)
* **Host** $\rightarrow$ **Outpost Commander**
* **Drawer** $\rightarrow$ **Shambhala Transceiver**
* **Guessers** $\rightarrow$ **Rebels / Bounty Hunters**
* **Spectator** $\rightarrow$ **Kasi Observer**

---

## 2. Dynamic Interface Phases & HUD States

* **Lobby Screen** $\rightarrow$ **KASI OUTPOST (STANDBY MODE)**
  * *Footer status details*:
    * *"ATMOSPHERE PRESSURE: DEGRADING — UPLINK BATTERY: 100%"*
* **Word Selection** $\rightarrow$ **SIGNAL INTERCEPTION (SELECTING SCHEMATIC)**
  * *Drawer selection prompt*: *"CHOOSE THE ENCRYPTED SCHEMATIC FOR TRANSMISSION"*
* **Drawing Phase** $\rightarrow$ **SHAMBHALA TRANSMISSION IN PROGRESS**
  * *Guessers input placeholder*: *"ENTER DECIPHERED SYMBOL..."*
* **Round Results** $\rightarrow$ **TRANSMISSION COMPLETE (DATA SECURED)**
  * *Scores Section Title*: *"UNITS ALLOCATION"*
* **Final Results** $\rightarrow$ **COMPLEX ASCENSION GRANTED (ESCAPE COMPLETE)**
  * *First Place (Winners)*: **Ascended to the Complex**
  * *Contained players*: **Contained in Kasi**

---

## 3. Real-Time HUD Alerts & Announcements

* **HUD Timer Bar Labels**:
  * *Normal timer*: **BUJJI CORE SIGNAL CALIBRATING** or **COMPLEX SCANNING BLOCKADE**
  * *Critical timer (<15s)*: **COMPLEX AIR-STRIKE ENGAGED** (or **COMPLEX BARRAGE IMMINENT**)
* **AI Core Security Log**:
  * Header label: **BUJJI Core Diagnostics Feed** or **PROJECT K Security Log**
  * *Broadcast mapping*:
    * *"SUBJECT CODENAME ONLINE"* $\rightarrow$ *"SUBJECT DETECTED. WEAPONIZED VEHICLE BUJJI ENGAGED."*
    * *"SUBJECT DISCONNECTED"* $\rightarrow$ *"UPLINK INTERRUPTED. SHAMBHALA REBEL OFFLINE."*
    * *"IDENTITY VERIFIED"* $\rightarrow$ *"SIGNAL RESOLVED. +100 UNITS TRANSFER COMPLETED."*
